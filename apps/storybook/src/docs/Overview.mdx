# Overview

`@flownamix/react-data-grid-kit` is an enterprise React data table package for dense product workflows: account books, operational queues, review worklists, and grouped business records.

Use Storybook for quick visual inspection, interaction states, and integration examples. Use VitePress for full API guidance, architecture notes, migration notes, and contribution docs.

The base row model, sorting pipeline, row-selection state, and optional local filtering are powered by TanStack Table. The package layer focuses on the enterprise UI contract: grouped operational states, responsive card rendering, selection behavior, theming, icon overrides, and accessibility.

Desktop and mobile examples share the same grouping, filtering, sorting, and selection contracts. Use Storybook viewport controls to inspect the mobile grouped-card rendering.
