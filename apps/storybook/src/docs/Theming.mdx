# Theming

The table ships with CSS custom properties for surface colors, borders, typography, row density, and motion timing. Override tokens in your app shell or wrap a region with `rdtg-theme-dark`. Group collapse/expand uses `--rdtg-motion-collapse`, defaulting to a calmer 500ms transition.

```css
.crm-shell {
  --rdtg-color-primary: #0f766e;
  --rdtg-color-surface: #ffffff;
  --rdtg-radius-md: 6px;
}
```
